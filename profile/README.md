## MuTMS

**MuTMS (Multi-Tenant Management System)** is a GPL 3.0-licensed suite of plugins for Moodle™ LMS that brings enterprise-grade capabilities — multi-tenancy, structured learning programs, certifications, privileged sessions, and more — to standard Moodle installations. Built on a clean, open codebase with no commercial restrictions, MuTMS is designed for organizations that need serious LMS functionality without vendor lock-in. Paid support will be available from Q2 2026.
